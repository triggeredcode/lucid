The idea

Engineers think in structure.

A system design is an outline of sections and sub-sections, a list of options with the rejected ones crossed out, a table that compares them and a diagram of how the parts connect. Lucid builds that document while you think out loud, so you never stop to format.

Why it exists

Made so you can take notes without typing.

For a while I couldn't type comfortably, but I still wanted to keep learning system design. A dictation app gives you a wall of text, so I built Lucid to give me the structure.

Speak the notes

Dictate with any app that pastes text. The notes are sent by themselves a moment after you stop, so no Enter is needed.

Speak the changes

“Cross out Memcached.” “Add a CDN in front of the web server.” “Undo.” Hold one key and everything you say is a command. Even diagrams can be said.

Always one step back

Every change by the model is one undo step, so a misheard word costs one “undo”. Read the story.

What a page is made of

Typed blocks, drawn the same way every time.

The model only chooses which block fits what you said and fills it in. It never writes LaTeX or drawing code; Lucid draws and typesets the blocks, so a page looks the same however it was dictated.

How it works

Talk, refine, export. You stay in charge.

  1. Say or type

    One input box. Dictate with any app that pastes text (Wispr Flow, OpenWhispr, VoiceNative), or just type. Your words are never lost: if the model cannot use them, they are kept as written.

  2. Lucid structures it

    A local model in LM Studio turns notes into blocks and places them under the right section.

  3. Refine by number

    “In block 3, add a row for cost.” Every change is one undo step, and any earlier change can be reverted on its own.

  4. Export

    A typeset PDF, Markdown, or a .lucid file with its history. AI agents can edit the same blocks.

Diagrams by voice

Say the parts, then the connections.

A ten-part diagram is hard to say in one breath, so there is a guided builder.

  • Say the components: “client, server, DNS, database”.
  • Then the connections: “client to server”.
  • Fix by number: “rename 3 to Cache”, “reverse 2”.
  • Tables have the same builder.

Block numbers

Say which block you mean.

Every block has a light number in the margin. Click one to see its parts, then talk about it.

  • “In block 3, add a row for cost.”
  • “Cross out item 2 of block 6.”
  • “Rename node 2 of block 4 to Cache.”

History you can trust

Take back one change, not just the last.

The panel lists what you said and every change to the page: by Lucid, by a builder, by an AI agent. Show scrolls to what a change touched. Revert takes back that one change and leaves later ones to other blocks alone.

A real PDF

Typeset, not screenshotted.

Numbered sections, real tables, vector diagrams and formulas, in a fixed house style. The PDF engine (Tectonic) comes with the app. Or export Markdown, with diagrams as Mermaid.

First time you open it (macOS)

Lucid is free and not notarized by Apple, so macOS asks once:

  1. macOS 15: System Settings → Privacy & Security → Open Anyway.
  2. macOS 13 and 14: right-click the app → Open → Open.
  3. Or in Terminal:
xattr -dr com.apple.quarantine /Applications/Lucid.app
First time you open it (Windows)

Run the installer. It installs Lucid for you (no administrator needed) and starts it. Lucid is free and not signed, so Windows SmartScreen may say “Windows protected your PC”:

  1. Click More info.
  2. Click Run anyway.

To remove it later: Settings → Apps → Lucid. The portable .zip needs no install: unpack it and run Lucid.exe.

First time you open it (Linux)

Debian, Ubuntu and relatives, from the .deb:

sudo apt install ./Lucid-*-linux-amd64.deb

Any distribution, from the .AppImage:

chmod +x Lucid-*-linux-x86_64.AppImage
./Lucid-*-linux-x86_64.AppImage

On Ubuntu 24.04 and newer an AppImage can stop with a sandbox message: use the .deb, or start the AppImage with --no-sandbox.

Check the download

Each release lists SHA-256 checksums in SHA256SUMS. On macOS and Linux, in the folder with both files: 

shasum -a 256 --ignore-missing -c SHA256SUMS

On Windows, in PowerShell, then compare the result with the line for your file: 

Get-FileHash .\Lucid-*-win-x64.exe -Algorithm SHA256
Build it yourself

Needs Node 22.12 or newer and pnpm 9. Works on macOS (Apple Silicon), Windows and Linux (x64). 

git clone https://github.com/triggeredcode/lucid.git
cd lucid
pnpm install
node scripts/fetch-tectonic.mjs
pnpm dev

For AI agents

A toolbox, not just an app.

Lucid is also an MCP server. With the app running, Claude Code, or a model in LM Studio’s chat, can read and edit the same blocks with the same safe tools. Every agent change is one undo step and appears in the history as the agent’s.

Privacy

Your notes stay on your computer.

No account, no analytics

Lucid has no server and sends nothing about you anywhere.

A model you run

The language model runs in LM Studio on your computer. Settings refuses an address that is not local.

Plain files

Every page is one JSON file in ~/Lucid that you can back up or move. The code is MIT-licensed and open.

Questions

Good to know.

Why does macOS warn me when I open it?

Lucid is a free open-source app without an Apple developer certificate, so it is not notarized. macOS asks you to allow it once (see “First time you open it” above). The download’s checksum lets you verify what you got, and the source is public.

Do I need a dictation app?

No. Dictation is optional: a dictation app pastes your words and Lucid takes the paste. You can just type. Wispr Flow, OpenWhispr (free, open source) and VoiceNative (free, macOS) are separate apps with their own privacy terms.

Which model does it use?

Lucid is evaluated with qwen/qwen3.8-27b in LM Studio. Another model can be named in Settings, but expect more misses. A request takes 10 to 25 seconds on a laptop.

Is it only for system design?

It was made for system-design and engineering notes, but a page is just headings, lists, tables and diagrams, so it suits any subject that has that shape. Note formats are plain data you can extend.

Which systems does it run on?

macOS 13 or newer on Apple Silicon, Windows 10 or newer (64-bit) and Linux (64-bit; a .deb for Debian and Ubuntu, an AppImage for other distributions). Not yet: Intel Macs, and Windows or Linux on ARM.

Every build is tested on GitHub’s own macOS, Windows and Ubuntu machines before a release (it starts, makes a PDF with a diagram, and connects an AI agent), but the Mac version has had the most everyday use. If something is off on Windows or Linux, please report it.
